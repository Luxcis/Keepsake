# 响应式布局适配

## 能力说明

「拾光集」前台与管理后台页面在电脑（≥1024px）、平板（640–1023px）、手机（<640px）三类视口下保持完整可用、排版协调。能力范围只包含前端样式与布局：不改变业务功能、数据接口、门禁/登录逻辑和文案内容，也不替换已确认的复古胶片视觉方向。

断点沿用 Tailwind CSS 默认值并按页面实际需要补充：

- 手机：`< 640px`
- 平板：`640px – 1023px`
- 桌面：`≥ 1024px`

全局约束：

- 全站页面在任意视口都不出现横向滚动。
- 固定头部占用高度通过统一 CSS 变量表达，页面主内容按该变量让位，避免逐页硬编码固定像素。
- 可点击控件在手机端的有效点击高度不小于 40px。
- 刘海屏/圆角屏使用 `env(safe-area-inset-*)` 适配，关键操作不被系统手势区遮挡。
- 现有设计令牌（纸张色、墨绿、陶土、阴影、字体）与组件样式保持，只调整断点下的尺寸、间距与排布。

## 顶部导航与内容让位

### Requirement: 固定头部不遮挡页面内容

- **WHEN** 访客在手机视口打开首页、足迹、旅行详情、时光轴或生日信
- **THEN** 固定头部包含品牌行与四项导航行，页面主内容从头部下沿开始
- **AND** 页面一级标题、首屏文字不被头部或移动导航遮挡
- **AND** 页面不出现横向滚动
- 验收：A1

### Requirement: 手机端导航可点击与选中态

- **WHEN** 访客在手机视口查看头部导航
- **THEN** 首页、足迹、时光轴、生日信四个入口均可点击，且每个入口的有效点击高度不小于 40px
- **AND** 当前页面入口显示可见的选中态
- 验收：A2

## 平板布局

### Requirement: 平板断点下的卡片与叙事排布

- **WHEN** 访客在 640–1023px 视口打开足迹、旅行详情或时光轴
- **THEN** 足迹页旅行卡片显示为两列，卡片间距不小于 16px
- **AND** 旅行详情照片网格显示为两列，图片保持完整比例
- **AND** 时光轴显示左右交替的双列叙事布局，中轴线、节点、日期、标题与简介互不重叠
- 验收：A3

## 桌面布局

### Requirement: 桌面断点下的宽度与列数

- **WHEN** 访客在 1440×900 视口打开首页、足迹、时光轴或生日信
- **THEN** 主内容水平居中，最大宽度不超过 1280px
- **AND** 足迹页旅行卡片显示为三列
- **AND** 首页首屏标题与简介文字不溢出容器，不与右侧照片拼贴重叠
- 验收：A4

## 生日信

### Requirement: 信封与信纸宽度自适应

- **WHEN** 访客在手机、平板或桌面视口打开生日信
- **THEN** 信封卡片与信纸宽度等于其父容器宽度，最大不超过 448px
- **AND** 信封翻盖与底部三角贴合卡片左右边缘，不出现两侧空隙
- **AND** 信纸正文不出现横向溢出
- 验收：A5

## 照片灯箱

### Requirement: 手机端灯箱控制与画面缩放

- **WHEN** 访客在手机视口打开旅行详情中的照片放大
- **THEN** 左右切换按钮位于屏幕边缘，不遮挡画面中心区域
- **AND** 图片与视频按视口完整显示，不被控制按钮裁切
- **AND** 访客可正常切换上一张/下一张并关闭灯箱
- 验收：A6

## 管理后台

### Requirement: 后台页面手机端可操作

- **WHEN** 管理员在手机视口登录后台并打开旅行管理、相册与照片、生日信、备份或站点设置
- **THEN** 页面不出现横向滚动
- **AND** 头部用户名、退出、返回前台入口、标签导航与工具栏按钮不重叠
- **AND** 表单、地点编辑行纵向堆叠，输入框宽度不超出屏幕
- **AND** 照片管理列表单列或双列展示，上传、排序、删除按钮保持可点击
- 验收：A7

## 动效与降级

### Requirement: 动效不破坏内容可见性

- **WHEN** 三类视口下正常开启动效
- **THEN** 首页首屏、足迹卡片、时光轴节点与信纸入场后内容完整可见
- **AND** 当系统启用 `prefers-reduced-motion: reduce` 时，上述内容直接呈现且位置正常
- 验收：A8
