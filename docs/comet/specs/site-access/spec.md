# 站点访问门禁

## 能力说明

站点访问门禁保护前台私人内容（旅行、时光轴、生日信等）。管理员在后台配置访问口令 `site_password`、可选的开放日期 `open_date` 与未开放提示语 `not_open_message`。访客在门禁卡片提交口令，`POST /api/site/unlock` 先按 IP 限速并校验口令：口令错误时直接在卡片内提示口令错误；口令正确但当前时间早于开放日期时，以弹窗展示未开放提示且不发放门禁会话；口令正确且已开放时发放 HttpOnly 门禁 Cookie，页面重新加载后展示私人内容。

开放日期按 Asia/Shanghai 自然日零点判定，留空或非法值视为不限制。未开放提示语留空时使用默认文案，`{date}` 统一替换为中文日期标签。管理员会话视同已解锁，开放日期之前仍可预览与管理；开放日期未到时，已持有的门禁 Cookie 也不放行私人内容。

## Requirement: 站点访问设置

- **WHEN** 管理员保存站点访问设置
- **THEN** 访问口令、开放日期与未开放提示语分别保存为 `site_password`、`open_date`、`not_open_message`
- **AND** `open_date` 为空或不是合法日期时不限制开放日期
- **AND** 开放日期按 Asia/Shanghai 自然日零点判定，日期当天 00:00 起视为已开放
- **AND** `not_open_message` 为空时使用默认未开放文案

## Requirement: 私人内容的门禁拦截

- **WHEN** 访客在没有有效门禁会话时请求私人内容接口
- **THEN** 服务端返回 401 `gate_required`
- **AND** 前端私密页面显示门禁卡片，输入口令解锁后重新加载该页内容
- **AND** 管理员会话视同已解锁，开放日期之前仍可访问私人内容
- **AND** 访问口令未配置时视为开放模式，访客可直接读取私人内容
- **AND** 开放日期未到时，即使访客持有已发放的门禁 Cookie，私人内容仍被拦截

## Requirement: 解锁时先校验访问口令

- **WHEN** 访客向 `POST /api/site/unlock` 提交非空 `password`
- **THEN** 服务端先执行按 IP 限速与口令校验，再判断开放日期
- **AND** 口令错误时返回 401 `gate_mismatch`，前端在门禁卡片内提示口令错误
- **AND** 口令错误时不返回未开放提示，也不出现未开放弹窗
- **AND** 访问口令未配置时返回 404 `gate_not_set`
- **AND** 请求缺少 `password` 时返回 400 `bad_request`

## Requirement: 未开放时返回未开放提示

- **WHEN** 访客提交正确口令，但当前时间早于开放日期
- **THEN** 服务端返回 403 `not_open_yet`，响应消息为渲染后的未开放提示语
- **AND** 提示语中的 `{date}` 替换为开放日期的中文标签（如「2099 年 1 月 1 日」）
- **AND** 服务端不发放门禁会话，访客保持未解锁状态

## Requirement: 未开放提示弹窗

- **WHEN** 门禁卡片收到 `not_open_yet`
- **THEN** 页面以弹窗展示未开放提示语，而不是在卡片内联显示该文案
- **AND** 弹窗提供明确的关闭入口，并支持点击遮罩或按 Esc 关闭
- **AND** 弹窗关闭后仍停留在门禁卡片，私人内容不可见
- **AND** 再次提交正确口令时可以再次看到未开放弹窗

## Requirement: 口令错误的内联提示

- **WHEN** 门禁卡片收到 `gate_mismatch`
- **THEN** 卡片内联显示「访问口令不正确。」
- **AND** 不出现未开放弹窗
- **AND** 输入框内容保留，访客可直接修改后重试

## Requirement: 解锁成功

- **WHEN** 访客提交正确口令且当前已到开放日期
- **THEN** 服务端返回 200 并发放 HttpOnly 门禁 Cookie
- **AND** 前端清除口令输入并重新加载当前页面内容
- **AND** 不出现未开放弹窗

## Requirement: 解锁限速

- **WHEN** 同一 IP 在 15 分钟内提交解锁请求超过 10 次
- **THEN** 服务端返回 429 `rate_limited`，前端提示「尝试次数过多，请稍后再试。」
- **AND** 达到限速后即使口令正确也不发放门禁会话
- **AND** 站点未开放期间的错误口令尝试同样计入限速

## Requirement: 其它错误提示

- **WHEN** 门禁卡片收到 `gate_not_set` 或其它错误
- **THEN** 卡片内联显示对应提示：口令未启用时说明需管理员在后台设置，网络异常时提示稍后再试
- **AND** 不出现未开放弹窗
