# 旅行详情照片浏览

## 能力说明

前台不再提供独立的照片收藏页面，照片浏览收敛到对应旅行的详情页。旅行详情通过 `GET /api/trips/{id}/photos` 读取该旅行的全部照片，在地点列表之后展示缩略图网格；点击任意可查看照片打开全屏灯箱，可查看大图、切换相邻照片，并在照片带实况视频时播放实况。

照片数据、签名 URL、排序和门禁策略均由现有服务端接口提供；本能力只调整前台页面结构、导航入口和展示交互。

依赖：`GET /api/trips/{id}/photos`（返回 `enabled` 与该旅行的照片数组，按 `sort_order`、`created_at` 升序）。

## 页面入口

### Requirement: 独立照片收藏页移除

- **WHEN** 访客查看桌面主导航或移动端导航，或访问 `/photos`
- **THEN** 导航中不再出现「照片收藏」或「照片」入口
- **AND** 访问 `/photos` 时重定向到 `/trips`，不渲染独立照片墙页面
- **AND** 旅行详情中不再显示跳转 `/photos` 的照片入口按钮
- 验收：A1

## 旅行详情照片列表

### Requirement: 照片网格展示

- **WHEN** 旅行详情加载完成，且该旅行存在照片
- **THEN** 在地点列表之后按接口返回顺序展示照片缩略图网格
- **AND** 卡片优先使用签名缩略图 `thumb_src`，带 `video_src` 的照片使用实况卡片，有标题的照片显示标题
- **AND** 缩略图不可用时显示现有签名失败提示，不渲染破图
- 验收：A2

### Requirement: 门禁降级

- **WHEN** 未解锁时打开旅行详情，照片或详情请求返回门禁要求
- **THEN** 页面显示 GatePrompt，不展示旅程正文或空网格
- **AND** 解锁后重新加载并展示旅程、地点与照片
- 验收：A5

### Requirement: 空态与存储提示

- **WHEN** 旅行没有照片
- **THEN** 显示「这一次旅行还没有精选照片」提示，不渲染空网格
- **AND** 存储后端未启用且没有照片时，显示存储未配置提示
- 验收：A4

### Requirement: 加载失败重试

- **WHEN** 旅行详情或照片请求失败，且错误不是门禁要求
- **THEN** 显示错误信息与重试入口
- **AND** 点击重试重新发起加载
- 验收：A6

## 灯箱查看

### Requirement: 灯箱查看与切换

- **WHEN** 点击详情页任意可查看照片
- **THEN** 打开全屏灯箱，显示该照片的显示尺寸图（`preview_src` 优先，回退 `src`）
- **AND** 支持 Esc 关闭、左右方向键与前后按钮切换，并预取相邻照片
- **AND** 带 `video_src` 的照片在灯箱中播放实况视频
- **AND** 没有可用显示地址的照片不打开灯箱
- 验收：A3
