# 目标

前台不再保留独立的「照片收藏」页面；照片改为在旅行详情中浏览。访客点击旅行足迹进入某段旅行的详情后，可以看到该旅行的照片列表，点击照片打开灯箱查看大图或实况照片。

# 范围

- 删除前台照片收藏页面及其路由入口：移除桌面导航「照片收藏」与移动端导航「照片」项。
- `/photos` 不再渲染照片墙，访问时重定向到 `/trips`，旧链接不会落到 404。
- 旅行详情页在旅程故事与地点列表之后加载并展示该旅行的全部照片：缩略图网格、照片标题、实况照片卡片。
- 详情页照片支持全屏灯箱查看，沿用现有 Esc 关闭、方向键/前后切换、相邻预取与实况播放能力。
- 详情页保留现有门禁降级：未解锁时显示 GatePrompt，解锁后重新加载旅程、地点与照片。
- 无照片时显示空态提示；存储后端未启用且无照片时显示存储未配置提示；加载失败显示错误与重试入口。
- 更新 README 的页面路由表，移除 `/photos` 并说明旅行详情包含照片浏览。

## 目录结构

### 修改

- web/src/views/TripDetailView.vue — 加载 `/api/trips/{id}/photos`，在地点之后渲染照片网格并接入灯箱；移除跳转 `/photos` 的「查看这次旅行的照片」按钮。
- web/src/router/index.ts — 移除 PhotoWallView 的懒加载路由，`/photos` 改为重定向到 `/trips`。
- web/src/components/AppHeader.vue — 移除桌面端「照片收藏」与移动端「照片」导航项。
- README.md — 页面路由表移除 `/photos`，旅行详情条目注明包含照片浏览。

### 删除

- web/src/views/PhotoWallView.vue — 独立照片收藏页。

### 明确不建

- 不新增服务端接口或数据表 — 复用现有 `GET /api/trips/{id}/photos` 与该旅行的照片排序。
- 不新增灯箱或实况播放组件 — 复用 `PhotoLightbox.vue`、`LivePhotoMedia.vue`。
- 不新增前台相册分组页面 — 详情页按后端返回顺序平铺展示，`album_id` 不参与分组。

# 非目标

- 不修改管理端的相册、照片上传、排序、说明与删除能力。
- 不修改后端照片接口、COS/本地存储签名逻辑或数据库结构。
- 不修改首页、时光轴、生日信页面，也不改变门禁、登录态或管理端权限模型。
- 不迁移、删除或重新上传任何已有照片数据。
- 不更新 `docs/demo.html` 静态设计稿和 `docs/plan.docx` 产品计划原文。

# 验收示例

- A1：桌面主导航不再出现「照片收藏」，移动端导航不再出现「照片」；访问 `/photos` 会重定向到 `/trips`，前台不再存在独立的照片收藏页面。
- A2：打开发布旅行的详情页，在旅程故事与地点列表之后按服务端返回顺序展示该旅行的照片缩略图网格；有标题的照片显示标题，带视频的照片以实况卡片呈现。
- A3：点击详情页任意可查看照片打开全屏灯箱，显示对应大图；支持 Esc 关闭、左右方向键与前后按钮切换；实况照片在灯箱中播放。
- A4：没有照片的旅行详情显示「这一次旅行还没有精选照片」空态，不渲染空网格；存储后端未启用且无照片时显示存储未配置提示。
- A5：未解锁时旅行详情显示门禁提示，解锁后回到该页并加载旅程、地点与照片。
- A6：详情或照片加载失败时显示错误信息与重试入口，点击重试重新发起加载。
- A7：`cd web && npm run build` 通过，且构建后的前端不再包含 PhotoWallView 页面代码。

# 关键决定

- 独立照片收藏页整体删除，照片浏览入口收敛到旅行详情；不保留按旅行切换的照片墙。
- `/photos` 保留为到 `/trips` 的重定向，避免旧书签或旧链接 404。
- 详情页照片按 `/api/trips/{id}/photos` 的返回顺序（`sort_order`、`created_at`）平铺展示，不按相册分组。
- 照片网格与灯箱复用现有 `PhotoLightbox`、`LivePhotoMedia` 及 `thumb_src`/`preview_src` 逻辑，保持实况照片播放能力。
- 照片区位于地点列表之后；无照片时显示空态文案，不整块隐藏。
- 移动端导航移除「照片」后保留「首页、足迹、时光轴、生日信」四项。

# Verification expectations

- 前端：`cd web && npm run build`（`vue-tsc -b` + Vite 构建）通过。
- 静态核对：`web/src` 中不再引用 `PhotoWallView.vue`，除 `/photos` 重定向外不存在指向照片收藏页的导航链接。
- 手工/浏览器核对：旅行详情的照片网格、灯箱键盘操作、实况播放、空态、门禁与错误重试符合验收示例。
