# 目标

首页不再使用固定的渐变占位图形，而是从站点全部已发布旅行照片中随机挑选真实照片呈现：首屏主视觉作为背景照片，简介拼贴区展示另外两张照片。每次打开或刷新首页都会重新随机，让访客每次看到的回忆不同；无照片、门禁未解锁或照片签名失败时回退现有渐变占位，不影响首页其余内容。

# 范围

- 服务端新增门禁组内的随机照片读接口，跨全部已发布旅行随机取照片，返回签名后的缩略图、预览与原图地址及所属旅行信息；只含照片条目，不含单独上传的视频。
- 首页主视觉背景与简介拼贴区改用随机照片，保留现有深色遮罩、排版与滚动动效。
- 随机照片为纯展示，不绑定点击、灯箱或跳转。
- 照片数量不足、门禁未解锁、存储未配置或签名失败时，对应位置保持现有渐变占位。

## 目录结构

### 新建

- server/internal/store/queries_photo.go — 增加跨旅行随机照片查询及返回类型（函数名实现时确定）。
- server/internal/handlers/photo.go — 增加随机照片列表处理函数，复用现有签名逻辑。
- server/internal/server/photos_random_test.go — 覆盖门禁、发布状态与媒体类型筛选、limit 边界与输出字段。
- docs/comet/changes/home-random-photos/specs/home-random-photos/spec.md — 本 capability 的完整目标规格。

### 修改

- server/internal/handlers/api.go — 在门禁路由组挂载 `GET /api/photos/random`。
- web/src/api/client.ts — 新增随机照片响应类型。
- web/src/views/HomeView.vue — 拉取随机照片并用于主视觉与简介拼贴，保留降级；样式段补充照片遮罩与图片填充规则。

### 明确不建

- 不新增照片表、相册表或独立「照片收藏」页面 — 复用现有 photos 数据与签名链路。
- 不引入服务端图片转码或海报生成 — 直接使用现有缩略图与预览签名。
- 不新增首页照片的人工挑选、置顶或排序配置 — 随机规则由接口直接决定。

# 非目标

- 不改变管理端照片管理、上传、排序与删除流程。
- 不改变旅行详情页、时光轴、生日信的照片展示与门禁行为。
- 不改变照片签名有效期、COS Key 规则与存储后端配置。
- 不新增前台照片墙区块或照片收藏入口。

# 关键决定

- 随机在服务端完成（跨已发布旅行、仅照片条目），前端只消费结果，避免前端逐个旅行拉取再合并。
- 首页一次请求 3 张照片：第 1 张用于主视觉背景，第 2、3 张用于简介拼贴两张卡片；不足 3 张时按顺序填充，缺位保持渐变占位。
- 随机接口位于门禁组内，未解锁返回 401 `gate_required`；首页捕获该错误后静默回退占位，不弹出解锁提示。
- 随机接口响应设置禁止缓存，保证每次打开或刷新首页重新抽取；同一页面停留期间不重新请求。
- 主视觉使用灯箱尺寸预览地址（为空回退原图），简介卡片使用缩略图地址，均要求地址非空才渲染图片。

# 验收示例

1. 随机照片接口只返回 `status = published` 旅行下的照片条目：草稿旅行的照片、单独上传的视频条目不会出现，返回条数不超过请求的 `limit`。
2. 未解锁门禁时请求随机照片接口返回 401 `gate_required`；解锁后返回照片数组，条目包含所属旅行 ID、标题以及非空的缩略图地址。
3. 首页首屏主视觉显示随机照片作为背景，并保留深色渐变遮罩，首屏标题、副标题与按钮清晰可读，不再显示纯渐变背景。
4. 首页简介拼贴区的两张照片卡片显示随机照片，保持现有三列/两列拼贴布局、圆角与悬停缩放效果。
5. 每次打开或刷新首页时照片组合重新随机；同一次页面停留期间照片不变化，不会在页面内自动轮换。
6. 门禁未解锁、存储未配置、可用照片少于 3 张或图片地址签名失败时，无照片的位置保持现有渐变占位，页面不出现破图、错误提示或空白区块，其它首页内容正常显示。
7. 首页随机照片为纯展示：点击主视觉或拼贴照片不会打开灯箱、不会跳转页面，光标不呈现可点击样式。

# 验证要求

- 服务端：在 `server/` 执行 `go build ./...` 与 `go test ./...` 通过；新增测试覆盖门禁 401、发布状态筛选、视频排除、limit 边界与地址字段。
- 前端：在 `web/` 执行 `npx vue-tsc --noEmit -p tsconfig.app.json` 与 `npx vite build` 通过；不使用 `npm run build`，避免改写被跟踪的 `tsconfig.app.tsbuildinfo`。
- 前端源码检查：首页照片元素不绑定点击处理，`HomeView.vue` 中无灯箱或路由跳转调用。
