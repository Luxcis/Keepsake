# 首页随机照片

## 概述

首页从站点全部已发布旅行照片中随机挑选 3 张真实照片：第 1 张作为首屏主视觉背景，其余两张放入简介拼贴区。随机发生在服务端，每次打开或刷新首页重新抽取；照片仅作展示，不提供点击、灯箱或跳转。门禁未解锁、照片不足、存储未配置或签名失败时，对应位置保持现有渐变占位，不影响首页其它内容。

## 需求

### 随机照片接口

系统提供门禁组内的只读接口 `GET /api/photos/random`，从全部已发布旅行中随机返回照片条目。

- 查询参数 `limit` 为期望条数，缺省 3，有效范围 1–12；非法值或越界值按缺省 3 处理。
- 随机池只包含 `trips.status = 'published'` 旅行下的 `photos.media_kind = 'photo'` 条目；草稿旅行照片与单独上传的视频条目不参与。
- 服务端按随机顺序返回，最多 `limit` 条；可用照片少于 `limit` 时返回实际数量，可能为空数组。
- 返回结构为 `{ enabled, photos: [...] }`。照片条目包含 `id`、`trip_id`、`trip_title`、`title`、`thumb_src`、`preview_src`、`src`。
- 存储后端启用时，`thumb_src` 为缩略图签名地址，`preview_src` 为灯箱尺寸签名地址，`src` 为原图签名地址；单个签名失败只让该字段为空串，不影响其它条目。
- 存储后端未配置时 `enabled` 为 `false`，各地址字段为空串。
- 未解锁门禁时返回 401，错误码为 `gate_required`，响应不包含任何照片地址。
- 响应禁止缓存（`Cache-Control: no-store`），保证每次打开首页重新抽取。

Scenario: 随机接口只返回已发布旅行的照片
  WHEN 站点存在已发布与草稿两类旅行，且已发布旅行下同时有照片与单独视频条目
  THEN 解锁门禁后请求随机接口，返回条目全部属于已发布旅行、全部为照片类型，且条数不超过 `limit`
  验收：A1

Scenario: 门禁阻止未解锁访客读取随机照片
  WHEN 站点启用门禁且访客尚未解锁
  THEN 请求随机照片接口返回 401 `gate_required`，响应不含照片地址
  验收：A2

### 首页主视觉背景

首页首屏主视觉区域使用随机结果中的第 1 张照片作为背景。

- 背景地址优先取该照片的 `preview_src`，为空时回退 `src`。
- 背景图铺满首屏区域并居中裁切，保持现有最小高度。
- 背景图上保留现有的深色渐变遮罩，首屏眉题、主标题、副标题与按钮在照片上仍清晰可读。
- 没有可用地址时，首屏保持现有纯渐变背景。

Scenario: 首屏主视觉展示随机照片
  WHEN 首页成功取到随机照片
  THEN 首屏显示该照片作为背景，深色遮罩保留，首屏文字与按钮清晰可读
  验收：A3

### 简介拼贴照片

首页简介区的照片拼贴使用随机结果中的第 2、3 张照片，分别替换现有两张渐变卡片。

- 每张卡片优先取 `thumb_src`，为空时回退 `preview_src`，再回退 `src`。
- 保持现有三列/两列拼贴布局、圆角、图片填充与悬停缩放效果。
- 某张照片没有可用地址时，该卡片保持现有渐变占位，另一张照常显示。

Scenario: 简介拼贴展示随机照片
  WHEN 首页成功取到至少 3 张随机照片
  THEN 简介拼贴的两张卡片分别显示第 2、3 张照片，布局与悬停缩放效果保持不变
  验收：A4

### 重新随机与降级

- 首页挂载时请求一次随机照片接口；每次打开或刷新页面重新抽取，页面停留期间不重新请求、不自动轮换。
- 接口返回 401、网络失败或其它错误时静默降级，不弹出解锁提示、不显示错误信息。
- 可用照片少于 3 张时按顺序填充：第 1 张给主视觉，第 2 张给第一张拼贴卡片，其余位置保持渐变占位。
- 图片地址为空或加载失败时保持渐变占位，页面不出现破图、空白区块或错误提示，其它首页内容正常显示。

Scenario: 每次打开首页重新随机
  WHEN 用户打开或刷新首页
  THEN 页面在挂载时请求一次随机照片并展示新组合；停留期间照片保持不变
  验收：A5

Scenario: 照片不可用时的占位降级
  WHEN 门禁未解锁、存储未配置、可用照片不足 3 张或签名地址为空
  THEN 对应位置显示现有渐变占位，页面不出现破图或错误提示，其它内容正常
  验收：A6

### 纯展示交互

首页随机照片只作视觉呈现，不绑定点击行为。

- 主视觉背景与简介拼贴照片均不打开灯箱、不跳转页面。
- 照片元素不使用可点击光标或按钮语义。

Scenario: 首页照片不可点击
  WHEN 用户点击首屏背景或简介拼贴中的照片
  THEN 页面不发生跳转，不打开灯箱，光标不呈可点击样式
  验收：A7
