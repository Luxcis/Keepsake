# 旅行详情照片浏览

## 能力说明

前台不再提供独立的照片收藏页面，照片浏览收敛到对应旅行的详情页。旅行详情通过 `GET /api/trips/{id}/photos` 读取该旅行的全部媒体条目，在地点列表之后展示缩略图网格；点击任意可查看条目打开全屏灯箱，可查看大图、切换相邻条目，并在条目带视频时播放。管理端可以单独上传视频，视频作为独立媒体条目与照片按同一排序混排展示。

照片数据、签名 URL、排序和门禁策略均由现有服务端接口提供；本能力负责前台页面结构、导航入口与展示交互。

依赖：`GET /api/trips/{id}/photos`（返回 `enabled` 与该旅行的媒体数组，按 `sort_order`、`created_at` 升序；每条记录包含 `media_kind`，取值为 `photo` 或 `video`）。

## 页面入口

### Requirement: 旅行列表入口文案

- **WHEN** 访客查看桌面主导航、移动端导航、`/trips` 页面或旅行详情页
- **THEN** 旅行列表入口统一显示「足迹」，页面中不再出现「旅行足迹」
- **AND** `/trips` 的路由标题为「足迹」，页面主标题为「我们的足迹」，旅行详情返回链接为「返回足迹」
- **AND** 移动端导航保持「足迹」文案，不使用其它别名
- 验收：A1

### Requirement: 独立照片收藏页移除

- **WHEN** 访客查看桌面主导航或移动端导航，或访问 `/photos`
- **THEN** 导航中不再出现「照片收藏」或「照片」入口
- **AND** 访问 `/photos` 时重定向到 `/trips`，不渲染独立照片墙页面
- **AND** 旅行详情中不再显示跳转 `/photos` 的照片入口按钮

## 旅行详情媒体列表

### Requirement: 照片网格展示

- **WHEN** 旅行详情加载完成，且该旅行存在照片条目
- **THEN** 在地点列表之后按接口返回顺序展示缩略图网格
- **AND** 照片卡片优先使用签名缩略图 `thumb_src`，带 `video_src` 的照片使用实况卡片，有标题的照片显示标题
- **AND** 缩略图不可用时显示现有签名失败提示，不渲染破图

### Requirement: 视频条目混排展示

- **WHEN** 旅行存在 `media_kind=video` 的条目
- **THEN** 视频条目与照片条目按同一接口顺序混排在同一网格
- **AND** 视频卡片以视频首帧作为画面并显示播放标记，不使用「签名生成失败」占位
- **AND** 视频卡片可点击进入灯箱；存储未启用、视频地址为空时不可点击
- 验收：A3

### Requirement: 门禁降级

- **WHEN** 未解锁时打开旅行详情，照片或详情请求返回门禁要求
- **THEN** 页面显示 GatePrompt，不展示旅程正文或空网格
- **AND** 解锁后重新加载并展示旅程、地点与媒体条目

### Requirement: 空态与存储提示

- **WHEN** 旅行既没有照片也没有视频
- **THEN** 显示「这一次旅行还没有精选照片」提示，不渲染空网格
- **AND** 存储后端未启用且没有媒体条目时，显示存储未配置提示

### Requirement: 加载失败重试

- **WHEN** 旅行详情或媒体请求失败，且错误不是门禁要求
- **THEN** 显示错误信息与重试入口
- **AND** 点击重试重新发起加载

## 灯箱查看

### Requirement: 灯箱查看与切换

- **WHEN** 点击详情页任意可查看的照片或视频条目
- **THEN** 打开全屏灯箱，照片显示显示尺寸图（`preview_src` 优先，回退 `src`），视频使用带播放控件的原生视频播放
- **AND** 支持 Esc 关闭、左右方向键与前后按钮切换，并预取相邻照片
- **AND** 带 `video_src` 的照片在灯箱中播放实况视频
- **AND** 切换到其它条目或关闭灯箱时停止视频播放，视频条目不参与相邻预取
- **AND** 没有可用地址的照片或视频不打开灯箱
- 验收：A3

## 管理端上传

### Requirement: 单独视频上传入库

- **WHEN** 管理端选择一个没有同名照片配对的 `video/mp4` 或 `video/quicktime` 文件
- **THEN** 前端为视频发起上传签名、直传并确认，创建一条 `media_kind=video` 的媒体记录
- **AND** 上传任务区显示该视频的进度、完成状态或失败原因，不再提示「视频不会单独上传」
- **AND** 同名照片 + 视频仍按实况照片处理，不额外创建视频记录
- 验收：A2

### Requirement: 视频大小上限

- **WHEN** 管理端上传视频对象
- **THEN** 服务端签名接口与确认阶段都接受不超过 400MB 的视频对象，超过 400MB 返回 400 且不入库
- **AND** 前端在上传前拒绝超过 400MB 的视频文件并给出跳过的原因
- **AND** 图片对象仍按不超过 30MB 校验，签名接口返回的 `max_bytes` 与媒体类型一致
- 验收：A4

### Requirement: 视频条目维护与删除

- **WHEN** 管理端在相册与照片页查看或删除一条视频记录
- **THEN** 视频记录与照片记录一起展示并支持标题、说明、排序与删除操作
- **AND** 删除视频记录时，接口返回前同步删除该视频对象，失败对象写入补偿任务队列
- **AND** 视频条目不作为旅行封面候选，封面选择列表只列出照片条目
- 验收：A6
