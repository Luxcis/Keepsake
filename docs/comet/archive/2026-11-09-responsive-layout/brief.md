# 目标

让「拾光集」现有页面在电脑（≥1024px）、平板（640–1023px）、手机（<640px）三类视口下都保持完整可用、排版协调：不出现横向滚动、内容被固定头部遮挡、卡片/表单拥挤溢出等问题，同时保留已确认的复古胶片视觉方向与现有动效降级策略。

# 范围

- 覆盖前台公开页面：首页、足迹、旅行详情、时光轴、生日信、404，以及公用的头部、页脚、门禁卡片、页面状态、照片灯箱。
- 覆盖管理后台页面：登录、旅行管理、相册与照片、生日信、备份、站点设置；后台保证手机端可完成常用操作。
- 手机端导航保留「品牌行 + 四项导航行」的两行顶部导航，修正内容遮挡并加大可点击区域。
- 桌面端保持现有复古电影册视觉，只精修间距、字号、栅格、对齐与大屏留白，不做整体视觉改版。
- 处理本次调查发现的具体问题：
  - 固定头部在手机端包含第二行导航，但页面内容统一按 74px 顶部内边距让位，导致手机端内容被移动导航遮挡。
  - 足迹列表仅 `md:grid-cols-3`，768–1023px 平板宽度下三列拥挤。
  - 生日信信封使用固定像素三角边框（120px/190px），与容器实际宽度不一致，手机与桌面都会出现两侧空隙。
  - 管理后台头部信息区、旅行地点编辑行、照片上传工具栏在窄屏可能溢出或换行错乱。
  - 照片灯箱左右切换按钮在手机端覆盖画面主体；首屏高度与字号在小屏/平板上的比例需要复核。
- 统一三类视口的间距、字号、网格断点与可点击区域，使同类页面在各断点下保持一致的视觉节奏。

## 目录结构

### 修改

- `web/src/components/AppHeader.vue` — 固定头部高度与移动端导航排布，避免遮挡页面内容。
- `web/src/App.vue` — 主内容顶部偏移改为跟随头部实际高度。
- `web/src/assets/styles/main.css` — 补充全局断点、间距、安全区与触摸目标基础样式。
- `web/src/views/HomeView.vue` — 首屏高度、标题字号与简介拼贴在手机/平板/桌面的比例。
- `web/src/views/TripsView.vue` — 旅行卡片网格在手机/平板/桌面的列数与间距。
- `web/src/views/TimelineView.vue` — 时间轴中轴线、节点与卡片在各断点的排布。
- `web/src/views/TripDetailView.vue` — 文章内边距、地点列表与照片网格的断点。
- `web/src/views/LetterView.vue` — 信封卡片与信纸宽度随容器自适应，消除固定像素空隙。
- `web/src/components/PhotoLightbox.vue` — 手机端切换按钮位置、图片/视频视口缩放与安全区。
- `web/src/components/GatePrompt.vue`、`web/src/components/PageState.vue`、`web/src/components/AppFooter.vue` — 小屏内边距与文案换行。
- `web/src/views/admin/AdminView.vue`、`AdminLoginView.vue`、`AdminTripsView.vue`、`AdminPhotosView.vue`、`AdminLetterView.vue`、`AdminBackupView.vue`、`AdminSettingsView.vue` — 后台头部、工具栏、表单与列表的窄屏重排。
- `web/index.html` — 视口配置与相关 meta，适配刘海屏安全区。

### 明确不建

- 不新建独立移动站点或设备专属路由 — 同一套页面通过响应式布局适配。
- 不引入 UI 组件库、CSS 框架或新的设计系统 — 沿用 Tailwind CSS 4 与现有设计令牌。
- 不新增后端接口、数据库字段或认证逻辑 — 本次只调整前端样式与布局。

# 非目标

- 不改变任何业务功能、数据接口、门禁/登录逻辑与文案内容。
- 不替换现有视觉主题（奶油白纸张、暖棕、低饱和绿、胶片颗粒），不做整体视觉改版。
- 不新增页面、组件库或动画效果，不调整既有 GSAP 动效的触发语义。
- 不处理浏览器兼容性以外的性能优化、SEO 或可访问性重构。

# Decisions

- Q1 适配范围：前台公开页面 + 管理后台一起适配；后台重点保证手机端可完成上传、编辑与设置。
- Q2 桌面端程度：保持已确认的复古胶片视觉，只精修间距、字号、栅格、对齐与大屏留白。
- Q3 手机端导航：保留两行顶部导航（品牌行 + 四项导航行），修正遮挡、压缩高度并加大可点击区域；不改为底部标签栏或汉堡菜单。

# 验收示例

1. 在 375×812 视口依次打开首页、足迹、旅行详情、时光轴、生日信，页面不出现横向滚动；固定头部（品牌行 + 导航行）不遮挡任一页面的一级标题，首屏内容从头部下沿开始。
2. 在 375×812 视口，头部四项导航均可点击且当前页面入口有可见选中态，每个导航项的可点击高度不小于 40px。
3. 在 768×1024 视口打开足迹页为两列卡片、旅行详情照片为两列网格、时光轴为左右交替双列叙事布局，标题、日期、简介与图片不重叠、不挤压成单字换行。
4. 在 1440×900 视口打开首页、足迹、时光轴、生日信，主内容水平居中且最大宽度不超过 1280px，足迹卡片为三列，首屏标题与简介文字不溢出容器、不与照片拼贴重叠。
5. 在 375×812、768×1024、1440×900 三个视口打开生日信，信封卡片与信纸宽度等于其父容器宽度（最大 448px），信封翻盖与底部三角贴合卡片左右边缘，无两侧空隙，信纸正文不横向溢出。
6. 在 375×812 视口打开旅行详情照片放大，灯箱左右切换按钮位于屏幕边缘且不遮挡画面中心区域，图片与视频完整落在视口内，可正常切换和关闭。
7. 在 375×812 视口登录管理后台并依次打开旅行管理、相册与照片、生日信、备份、站点设置，页面不出现横向滚动，头部信息、标签导航与工具栏按钮不重叠，表单与地点编辑行纵向堆叠且输入框不超出屏幕。
8. 三类视口下正常开启动效时，首页首屏、足迹卡片、时光轴节点与信纸入场后内容完整可见；模拟 `prefers-reduced-motion: reduce` 时这些内容直接呈现且位置正常。
