# 生日信开信与阅读

## 能力说明

生日信页面在信件开启「揭晓」（`reveal_enabled = true`）时，先展示一个可拆开的信封。访客点击「拆开这封信 ✉」后，页面按四段连续动画完成开信：翻开信封封口 → 从信封内露出一部分折起的空白信纸 → 信纸向上完全抽出并让信封向下淡出 → 折叠信纸展开成完整信纸。动画结束后页面稳定为常规阅读版式，正文完整可读。动效不可用时直接呈现完整信纸，不播放动画。

开信动画是纯前端交互，信件内容仍来自 `GET /api/letter`，不改变接口、数据或管理后台的编辑行为。

## 信封展示

- **WHEN** 访客打开生日信页面，信件存在且 `reveal_enabled = true`
- **THEN** 显示信封卡片（渐变信封底、底部三角、可翻转的封口、`For You` / `WITH LOVE` 标签）与「拆开这封信 ✉」按钮
- **AND** 信封卡片宽度等于父容器宽度、最大不超过 448px，封口与底部三角贴合卡片左右边缘、两侧无空隙
- **AND** 信封阶段页面不显示信纸正文

## 开信动画

整套动画约 2.2 秒，四段连续播放，不需要额外点击；按钮是唯一触发点，信封卡片本身不额外绑定点击。

### Requirement: 开封与露纸

- **WHEN** 访客点击「拆开这封信 ✉」
- **THEN** 信封封口沿卡片上沿向上翻转打开，信封本体留在原位
- **AND** 折起的信纸从信封内部向上露出，露出高度约为折叠高度的 40%–60%
- **AND** 露出阶段纸面保持空白，不显示抬头、标题或段落，信封此时完整可见
- 验收：A1

### Requirement: 抽出与信封隐藏

- **WHEN** 露纸阶段结束
- **THEN** 信纸继续向上移动，直到完全抽出、信纸下沿高于信封上沿
- **AND** 信封同时向下移动并逐渐淡出，最终完全不可见
- **AND** 抽出过程中信纸始终位于信封之上，不被信封或翻开的封口遮挡
- 验收：A2

### Requirement: 展开成信

- **WHEN** 信纸完全抽出
- **THEN** 折叠信纸向下展开，纸面高度从折叠高度增长到完整信纸高度，折痕随之消失
- **AND** 正文在展开过程中随纸面展开淡入，展开完成时标题、全部正文段落、日期与落款完整可见，文字与纸面背景均未被裁切
- **AND** 折叠与抽出阶段纸面始终不显示文字
- 验收：A3

### Requirement: 阅读版式稳定

- **WHEN** 展开完成
- **THEN** 页面呈现与改动前一致的常规信纸版式：宽度等于父容器宽度且不超过 448px，留白与行距沿用现有 `.letter-paper` 样式
- **AND** 信封、按钮与动画副本全部移除，没有残留元素或空白占位
- **AND** 信纸顶边停在最终阅读位置，动画结束到阅读态之间不出现位置突跳；页面可正常滚动，语音彩蛋等其他区块位置正确
- 验收：A4

### Requirement: 动效降级

- **WHEN** 系统启用 `prefers-reduced-motion: reduce`，或 GSAP 动态加载失败
- **THEN** 点击按钮后直接显示完整信纸，不播放翻盖、露纸、抽出或展开动画
- **AND** 信件内容完整可读，不残留信封与按钮
- 验收：A5

### Requirement: 重复点击保护

- **WHEN** 动画播放期间再次点击「拆开这封信 ✉」
- **THEN** 不重启动画、不重复创建时间线、不产生跳帧或元素闪回
- **AND** 动画完成后信封与按钮不再出现，再次点击没有可见效果
- 验收：A6

### Requirement: 多视口

- **WHEN** 在手机（375px）、平板（768px）与桌面（1280px）视口执行完整开信流程
- **THEN** 四个阶段的画面都完整显示，信纸与信封没有横向溢出
- **AND** 信封与抽出的信纸保持同一宽度并居中，两侧不出现空隙
- 验收：A7

## 未开启揭晓的信件

- **WHEN** 信件 `reveal_enabled = false`
- **THEN** 不显示信封、按钮与开信动画，直接显示信纸正文，行为与改动前一致

## 交互与实现约束

- 动画使用现有 `compositions/motion.ts`：动效模块动态加载，视图卸载时用 `gsap.context(...).revert()` 清理未完成的时间线。
- 折叠信纸与最终阅读版式使用同一份信纸内容组件，折叠态只是裁切与位移，不另写一套排版。
- 折叠高度以信封卡片高度为参照（约占卡片高度的 40%），折叠态与展开态宽度一致，展开时不发生文字重排。
- 不新增前端依赖，不新增音效或其他特效。
