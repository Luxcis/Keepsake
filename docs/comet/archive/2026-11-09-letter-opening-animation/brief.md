# 目标

生日信页面点击「拆开这封信」后，用一段连续的分阶段动画替代现在「翻盖转开 → 信纸直接淡入」的效果：先翻开信封封口并露出一部分折起的信纸；随后信纸向上完全抽出、信封同时向下移动并逐渐淡出隐藏；信纸完全抽出后，折叠的信纸向下展开成完整信纸，最终稳定在与改动前一致的阅读版式上，正文完整可读。

# 范围

- 只覆盖生日信前台的「拆信 → 阅读」交互：`web/src/views/LetterView.vue`，以及为复用信纸正文新抽出的 `web/src/components/LetterCard.vue`。
- 沿用现有动效基础设施 `web/src/compositions/motion.ts`：GSAP 动态加载、`prefers-reduced-motion` 与模块加载失败时完全降级、`gsap.context(...).revert()` 卸载清理；不新增前端依赖。
- 信封视觉沿用现有配色与层次（渐变底、底部三角、翻盖、`For You` / `WITH LOVE` 标签），只调整层次组织与动画编排，不改视觉语言。
- 信纸版式沿用现有 `.letter-paper` 样式与宽度约束（等于父容器宽度、最大 448px、正文无横向溢出）。
- 折叠信纸与最终阅读版式使用同一份信纸内容与样式，避免两套排版产生差异。
- 降级路径保持：动效不可用（减少动效或 GSAP 加载失败）时，点击「拆开这封信」直接显示完整信纸。

## 目录结构

### 新建

- web/src/components/LetterCard.vue — 信纸正文（抬头、标题、全部段落、日期与落款）的展示组件，供动画中的折叠信纸与最终阅读版式复用同一份内容与样式。

### 修改

- web/src/views/LetterView.vue — 把「翻盖 → 信纸淡入」改成四段连续动画（翻盖打开并露出折叠信纸 → 信纸完全抽出且信封下移淡出 → 折叠信纸展开 → 稳定为阅读版式），并处理重复点击、卸载清理与降级。

### 明确不建

- 独立动画编排模块或状态机 — 单一视图内的四段式时间线用 GSAP timeline 足够，不为一次性交互新增抽象层。
- 新增前端测试框架或截图基线 — 仓库当前没有前端测试运行器，沿用 `vue-tsc`、`vite build` 与浏览器实测。
- 服务端与接口改动 — 开信动画是纯前端行为，`/api/letter` 与 `reveal_enabled` 语义保持不变。

# 非目标

- 不改信封与信纸的配色、装饰符号、字体、字号与留白。
- 不改管理后台的生日信编辑、`reveal_enabled` 开关与语音彩蛋逻辑。
- 不改 `/api/letter` 接口、数据表结构或其他页面的动效。
- 不新增音效、粒子、彩带等额外特效。
- 不提供「重播动画」入口，拆开后即为阅读态。

# 验收示例

- A1：点击「拆开这封信 ✉」后，先看到信封封口向上翻开，信封本体仍留在原位；随后一部分折起的空白信纸（纸面无文字）从信封内向上露出，信封此时仍完整可见。
- A2：信纸继续向上完全抽出（信纸下沿高于信封上沿），信封同时向下移动并逐渐淡出至完全不可见；抽出过程中信纸始终显示在信封之上，不被信封遮挡。
- A3：信纸完全抽出后，折叠的空白信纸向下展开为完整信纸，展开过程中随纸面展开显示出正文，展开完成后标题、全部正文段落、日期与落款完整可见，文字与纸面背景均未被裁切，折痕消失。
- A4：动画结束后页面稳定为与改动前一致的阅读版式（信纸宽度等于父容器宽度且不超过 448px，留白与行距不变），没有残留的信封元素或空白占位，信纸不出现位置突跳。
- A5：系统开启「减少动效」或 GSAP 模块加载失败时，点击「拆开这封信」后直接显示完整信纸，不播放任何动画阶段，信件可正常阅读。
- A6：动画进行期间重复点击「拆开这封信」不会重启动画或产生跳帧；动画完成后信封与按钮不再出现，页面可正常滚动阅读。
- A7：在手机（375px）、平板（768px）与桌面（1280px）视口下，开信动画各阶段与展开后的信纸都完整显示，无横向溢出、无两侧空隙。

## Decisions

触发方式沿用现有「拆开这封信 ✉」按钮，作为唯一触发点，信封卡片本身不额外绑定点击。折叠信纸的折叠高度以信封卡片高度为参照（约占卡片高度的 40%），折叠态与展开态宽度一致（等于信纸最终宽度），展开时不发生文字重排。折叠与抽出阶段纸面保持空白，只用与最终信纸一致的底色、纸纹和折痕表达折叠；展开阶段纸面变高的同时淡入正文，展开完成时正文全部可见。展开阶段直接使用真实信纸内容（`LetterCard`），动画结束后由同一内容接管为常规阅读版式，不保留动画副本。整套动画分为翻盖打开、露出折叠信纸、信纸抽出且信封下移淡出、信纸展开到位四段，总时长约 2.2 秒。
